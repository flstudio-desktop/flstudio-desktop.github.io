Project guide

FL Studio project files on Windows — save, backup & move guide

Manage FL Studio project files on Windows. Save locations, auto-save, backup folder, move projects to another PC with zipped loop package and recover after crashes.

Project files

FL Studio project file formats

FormatExtensionWhat it contains
FL Studio project.flpAll patterns, mixer settings, plugin settings (not audio files)
Zipped project.zipExport with File > Export > Zipped loop package (includes audio)
FL Studio template.flpSaved to templates folder, appears in New from template
.flp files do NOT embed audio samples. They reference file paths. If you move samples or open the project on another PC, missing audio errors will appear. Use File → Export → Zipped loop package to bundle everything.
Save & backup

Save and backup your FL Studio projects

  • Save: Ctrl+S saves the current project to its last location
  • Save as: Ctrl+Shift+S saves a new copy with a new name
  • Auto-save: Options → General Settings → enable Auto-save every X minutes
  • Backup folder: FL Studio auto-saves backups to %USERPROFILE%\Documents\Image-Line\FL Studio\Backup
Default project locations
# Main projects folder:
%USERPROFILE%\Documents\Image-Line\FL Studio\Projects
# Auto-save backups:
%USERPROFILE%\Documents\Image-Line\FL Studio\Backup
# Templates:
%USERPROFILE%\Documents\Image-Line\FL Studio\Projects\Templates
Move projects

Move a project to another PC

  • 1

    Export as zipped loop package

    File → Export → Zipped loop package (.zip). This bundles the .flp file together with all referenced audio samples into one archive.

  • 2

    Copy to the other PC

    Transfer the .zip file via USB, cloud storage or network share.

  • 3

    Extract and open

    Extract the zip, open the .flp inside. Any VST plugins used in the project must also be installed on the destination PC.

FAQ

Project file questions

Recover a project after FL Studio crashed
Check the auto-save backup folder: %USERPROFILE%\Documents\Image-Line\FL Studio\Backup. FL Studio saves backups every few minutes if auto-save is enabled. Open the most recent backup. Also check the Recent Projects list in File menu — FL Studio may have saved before the crash.
Missing samples when opening an old project
The .flp file references audio by file path. If samples were moved, FL Studio shows a missing file dialog. Browse to the new location to relink. Or use File → Find missing samples to batch-relink.
Can I open FL Studio projects in other DAWs?
Not directly — .flp is a proprietary format. To share with Ableton, Logic, etc., export stems: File → Export → Wave file for each track. Or export MIDI patterns from the Piano Roll for melodic elements.
