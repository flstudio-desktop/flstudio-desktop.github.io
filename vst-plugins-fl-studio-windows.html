VST guide

VST plugins in FL Studio on Windows — add, scan & fix guide

Set up VST and VST3 plugins in FL Studio on Windows. Add plugin folders, run a scan, fix plugins not showing, reset the blacklist and handle 32-bit plugins.

FL Studio supports VST2 and VST3 plugins. VST3 is the modern standard — use it if your plugin offers both. 32-bit plugins require a bridge and are not recommended.
Add VST folder

Add your VST plugin folder to FL Studio

  • 1

    Open File Settings

    In FL Studio: Options → Manage plugins. Or press F10 → File tab.

  • 2

    Add your VST folder

    In the VST plugins extra search folder section, click the folder icon and browse to where your VST plugins are installed. Common paths:

    Default VST3 paths on Windows
    C:\Program Files\Common Files\VST3\
    C:\Program Files\Steinberg\VSTPlugins\
    C:\Program Files\VSTPlugins\
    # Check your plugin installer for the actual install path
  • 3

    Scan for plugins

    Click Find more plugins. FL Studio scans the folder and adds new plugins to the Plugin Database. This may take a few minutes on first scan.

  • 4

    Verify plugins appear

    In the Plugin database panel (View → Plugin database or Ctrl+F8), search for your plugin. Right-click and send to current channel to test it.

Common issues

VST plugin problems and fixes

Plugin installed but not showing in FL Studio
Plugin folder not added or scan not run
Options > Manage plugins > add folder > Find more plugins
Plugin causes FL Studio to crash on load
Incompatible or corrupt plugin, or 32-bit plugin
Check plugin blacklist in Options > Manage plugins > Reset blacklisted
Plugin shows in list but makes no sound
Plugin not properly activated or wrong routing
Check if plugin requires separate activation/licence
32-bit plugin not loading
FL Studio 64-bit cannot load 32-bit DLLs directly
Use jBridge or update to a 64-bit version of the plugin
Plugin blacklist

Reset the plugin blacklist

When FL Studio crashes during a plugin scan, it adds that plugin to a blacklist and skips it in future scans. To reset:

FL Studio
# Options > Manage plugins > Plugins tab
# Click "Reset" next to the Blacklisted plugins count
# Then run Find more plugins again
# Or delete the blacklist file manually:
%APPDATA%\Image-Line\FL Studio\Plugins\plugin.db
FAQ

VST plugin questions

Where does FL Studio store plugin data on Windows?
FL Studio keeps plugin database and settings in %APPDATA%\Image-Line\FL Studio. Plugin presets are stored in %APPDATA%\Image-Line\FL Studio\Presets. Your actual VST .dll/.vst3 files stay in the folder where the plugin installer put them.
Can I use VST plugins from Ableton in FL Studio?
Yes. VST plugins are not DAW-specific. Any VST2 or VST3 plugin installed on your Windows PC can be used in both FL Studio and Ableton (and any other DAW). Just point FL Studio to the correct plugin folder.
FL Studio scanning plugins takes forever
Large plugin libraries (hundreds of plugins) can take 10-20 minutes on first scan. Subsequent scans only check new or changed plugins. You can also scan a single folder instead of all folders to speed it up.
