FL Studio plugins not showing — fix VST not appearing guide

VST plugins installed but not showing in FL Studio on Windows? Add the plugin folder, run a rescan, reset the blacklist and fix 32-bit vs 64-bit issues.

If a VST plugin is installed but not showing in FL Studio, the most common cause is that the plugin's folder has not been added to FL Studio's search paths.
Fix 1

Add the plugin folder and rescan

  • 1

    Open Manage plugins

    Options → Manage plugins (or F10 → File tab).

  • 2

    Add the VST folder

    In VST plugins extra search folder, click the folder icon and add the folder containing your .dll or .vst3 files. Common paths: C:\Program Files\Common Files\VST3 or C:\Program Files\VSTPlugins.

  • 3

    Click Find more plugins

    FL Studio scans the folder for new plugins. Wait for the scan to complete.

  • 4

    Check Plugin database

    Open View → Plugin database (Ctrl+F8) and search for the plugin by name.

Fix 2

Reset the plugin blacklist

If a plugin crashed during a previous scan, FL Studio blacklists it and skips it in future scans:

FL Studio
# Options > Manage plugins > Plugins tab
# Find "Blacklisted" count and click Reset
# Or delete the blacklist manually:
C:\> del "%APPDATA%\Image-Line\FL Studio\Plugins\plugin.db"
# Then rescan: Options > Manage plugins > Find more plugins
Fix 3

Check plugin compatibility

32-bit plugin not loading in FL Studio 64-bit
FL Studio 64-bit cannot directly load 32-bit .dll plugins
Use jBridge or install 64-bit version of the plugin
Plugin installed but greyed out in FL Studio
Plugin needs activation or licence not detected
Run plugin standalone first to activate, then reopen FL Studio
VST3 plugin not scanning correctly
Corrupt .vst3 bundle or missing Visual C++ dependency
Reinstall the plugin, install latest vc_redist.x64.exe
FAQ

Plugin visibility questions

Plugin shows in Plugin database but not in Channel Rack
Right-click the plugin in the Plugin database and choose Send to Channel Rack. Alternatively, in the Channel Rack, click an empty channel and browse to the plugin in the browser on the left.
Plugin worked before but disappeared after FL Studio update
The plugin database may have been reset. Re-run Options → Manage plugins → Find more plugins. The plugin folder paths should still be saved from before the update.
