Install guide

How to install FL Studio on Windows — step-by-step guide 2026

Install FL Studio 25 on Windows 10 and 11. Download, run the installer, set up ASIO audio, register your licence and fix common install errors.

FL Studio does not require administrator rights for the default install. It installs to your user folder by default. No reboot required.
Installation

Install FL Studio on Windows — step by step

  • 1

    Download the installer

    Download flstudio_win64_25.2.5.5319.exe from the download page. The file is about 1.2 GB and comes directly from Image-Line's CDN.

  • 2

    Run the installer

    Double-click the .exe. The FL Studio installer is a standard wizard — accept the licence agreement, choose your install directory (default is fine) and click Install.

  • 3

    Launch FL Studio

    After install, open FL Studio from the Start menu or the desktop shortcut. The trial version starts immediately — no login required to use the free trial.

  • 4

    Set up audio (ASIO)

    Go to Options → Audio Settings. Change the Input/Output driver from DirectSound to ASIO for low-latency monitoring. See the full ASIO setup guide.

  • 5

    Register your licence (if purchased)

    If you have a paid licence: Help → Unlock FL Studio. Enter your email and click unlock. Your licence is tied to your Image-Line account, not to the machine.

After install

First launch checklist

  • Set audio driver to ASIO in Options → Audio Settings
  • Set buffer size to 256 or 512 samples as a starting point
  • Set sample rate to 44100 Hz (or 48000 Hz if your interface uses it)
  • Scan for VST plugins: Options → Manage plugins → Find more plugins
  • Test with a default template: File → New from template

FAQ

Install questions

Do I need to uninstall the old version before updating?
No. The FL Studio installer updates in-place. Run the new installer over the existing version and it will update. Your projects, settings and plugins are preserved. See update guide.
Can I install FL Studio on multiple computers?
Yes. Your FL Studio licence is linked to your Image-Line account, not tied to hardware. Install on as many machines as you own and log in with your Image-Line credentials to activate.
The installer says "not a valid Win32 application"
You downloaded the wrong version (macOS instead of Windows) or the file is corrupt. Download the Windows 64-bit installer again: the filename should contain win64.

Audio crackling after install?

Set up ASIO for low-latency audio.
